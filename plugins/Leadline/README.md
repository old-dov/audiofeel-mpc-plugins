# Leadline (AudioFeel)

Monophonic lead synth for Akai MPC standalone and VST2 hosts. A unison stack of 1-7 oscillators (sine, triangle, saw or square, detuned and spread across the stereo field), a sine sub, a 24 dB resonant low-pass with drive, two ADSR envelopes, glide with optional legato, a vibrato that fades in, pulse-width modulation, and a ping-pong delay.

- **OSC**: Unison, Detune, Stereo, Sub, Wave, Pulse Width, PWM Depth/Rate, Octave, Glide, Legato, Bend Range.
- **FILTER / VCF EG**: Cutoff, Resonance, Env Amount (signed), Drive, Key Track, filter ADSR.
- **VCA EG**: amp ADSR, Velocity, Volume. **MOD**: Vib Rate/Depth/Delay (the mod wheel adds more vibrato). **DELAY**: Time, Feedback, Mix.

Programs: Init Lead, Supersaw Lead, Soft Sine Lead, Square Mono, Screamer, Trance Pluck, Portamento Lead, Hoover Stack, Retro Pulse, Warm Triangle, Glass Lead, Acid Lead, Epic Stack, Whistle.

Not implemented: polyphony, sustain pedal. Last-note priority with return to the previous held note.
