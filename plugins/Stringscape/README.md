# Stringscape (AudioFeel)

A synthesized string orchestra for Akai MPC standalone and VST2 hosts. 8 voices. Each voice is an ensemble of detuned saws (plus optional octave-down and octave-up layers) through a bowed-string style low-pass that opens as the note blooms, a soft body resonance, a vibrato that fades in, and a touch of bow noise. Chorus and a hall reverb at the output.

- **Section**: Violins, Violas, Cellos, Basses, Full (sets brightness, vibrato rate, bow noise and a low layer).
- **Articulation**: Legato, Staccato, Pizzicato, Tremolo (Attack and Release apply to Legato and, partly, Tremolo).
- **Playing it**: velocity sets loudness, brightness and bite; mod wheel, aftertouch and the Dynamics knob make a crescendo (louder, brighter, deeper vibrato); Bow adds a scrape and a slightly flat start; Humanize gives each note its own small offsets; Mono is a solo line (last key wins, legato between held keys, Glide).
- **VOICE**: Brightness, Ensemble, Vibrato, Bow Noise, Low Layer, High Layer, Bend Range. **ENV**: Attack, Release. **FX**: Volume, Chorus Mix, Reverb Mix / Size / Damp.

Programs: Full Ensemble, Solo Violin, Solo Cello, Violins Legato, Violas Warm, Cellos Epic, Basses Low, Slow Swell, Staccato Strings, Pizzicato, Tremolo Tension, Octave Strings, Hall Strings.

Honest limits: this is a synth that imitates strings, not a sample library; it is meant for pads, swells and underscore, not for exposed solo lines. No key-switching, no velocity layers, no real legato transitions. Desktop builds have no custom UI; the MPC shows touch pages.
